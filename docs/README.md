# Documentación del proyecto

El [README principal](../README.md) presenta el proyecto, la compilación y un ejemplo de ejecución. Los enlaces a código y resultados de estas guías apuntan a archivos del repositorio.

## Guías

- [Estructura y funcionamiento](GUIA_ESTRUCTURA.md): carpetas, clases Java y flujo de las consultas.
- [Operación de Hadoop](README_Hadoop.md): perfiles `cluster` y `single`, arranque, ejecución y diagnóstico en las VM.
- [Uso práctico de Hadoop y HDFS](Guia_practica_Hadoop_HDFS.md): navegación, transferencia de archivos y comandos frecuentes.
- [Comparación de rendimiento](GUIA_COMPARACION.md): preparación y medición en uno y varios nodos.

## Resultados

- [Resultados de las consultas](RESULTADOS_CONSULTAS.md): salidas e interpretación de las cinco consultas.
- [Benchmark y calidad](RESULTADOS_BENCHMARK.md): tiempos, CPU, memoria, métricas y limitaciones.
- [Resumen de la ejecución local](../results/local/README.md): referencia de resultados locales junto a sus archivos.
